# Zelda Pokémon TTRPG auf dem iPhone

## Einmalig veröffentlichen (GitHub Pages)

1. Erstelle auf github.com ein neues **öffentliches** Repository, z. B. `zelda-ttrpg`.
2. Lade die **Dateien aus diesem Ordner direkt ins Stammverzeichnis** des Repositories hoch (nicht den übergeordneten Ordner und nicht die ZIP-Datei).
3. Öffne **Settings → Pages**. Unter **Build and deployment** wähle **Deploy from a branch**, Branch `main`, Folder `/(root)`, dann **Save**.
4. Warte auf die Pages-Adresse, typischerweise `https://DEINNAME.github.io/zelda-ttrpg/`. Öffne diese Adresse auf dem iPhone in **Safari**.
5. Safari: **Teilen → Zum Home-Bildschirm → Hinzufügen**. Starte künftig über das neue Symbol.
6. Öffne das Spiel einmal mit Internet, damit die Dateien zwischengespeichert werden. Danach sollte der Rechner auch offline starten.

## Spielstände

Team, KP und importierte Kataloge werden lokal in Safari/Home-Bildschirm-Web-App gespeichert, **nicht** auf GitHub hochgeladen. Der Speicher kann durch iOS oder das Löschen von Websitedaten entfernt werden. **Exportiere deshalb regelmäßig das Team über „Team als TXT speichern“**. Bei Wechsel der Webadresse sind Speicherstände nicht automatisch übertragbar.

## Hinweise

- Nur über HTTPS (GitHub Pages) funktioniert die Offline-Installation zuverlässig. Das Öffnen einer `index.html` aus der Dateien-App reicht nicht aus.
- GitHub Pages ist bei einem öffentlichen Repository öffentlich zugänglich. Keine privaten Daten oder Spielstände ins Repository laden.
- Wenn eine alte Version bereits im Browser gespeichert ist, können importierte Kataloge die eingebauten neueren Kataloge überlagern.
- Die App wurde technisch paketiert, aber nicht auf einem realen iPhone getestet.
